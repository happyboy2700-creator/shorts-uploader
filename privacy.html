최종 수정: 2026-10-28

1. 앱의 용도

Shorts Uploader는 운영자 본인의 Google 계정으로만 로그인해, 운영자가 직접 만든 영상을 운영자의 YouTube 채널에 올리고 공개 상태와 조회 수를 확인하는 데만 씁니다. 다른 사람은 이 앱을 쓰지 않습니다.

2. 접근하는 정보

YouTube Data API로 운영자 채널의 영상 업로드, 업로드한 영상의 공개 상태 변경, 채널·영상 통계 읽기만 합니다. Google 사용자 데이터를 판매하거나 제3자와 공유하지 않으며, 광고나 다른 목적으로 쓰지 않습니다.

3. 저장

로그인 토큰은 운영자의 컴퓨터에만 저장되며 외부 서버로 보내지 않습니다. 운영자는 언제든 Google 계정의 보안 설정(타사 앱 액세스)에서 권한을 취소할 수 있습니다.

4. Google API 서비스 사용자 데이터 정책

이 앱이 Google API에서 받은 정보를 쓰는 방식은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

English summary. Shorts Uploader is used only by its operator with the operator's own Google account. It uploads the operator's own videos to the operator's YouTube channels, changes their privacy status, and reads channel/video statistics. No Google user data is sold, shared with third parties, or used for advertising. Tokens are stored only on the operator's computer. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
